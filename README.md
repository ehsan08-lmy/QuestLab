# QuestLab — Assignment 5

A responsive JavaScript project demonstrating three tasks from Assignment 5: JavaScript Basics (DOM Manipulation & Events).

## Tasks
- **Task 1 — Code Breaker:** inclusive random code generation, conditions, invalid-input handling, attempts, history, and restart.
- **Task 2 — Quest Board:** ten data objects, DOM rendering, tag filter, priority sort, event delegation, progress calculation, and a three-item In progress limit.
- **Task 3 — Character Creator:** live preview, custom validation rules, field-level accessible errors, error summary/focus management, DOM-generated success result, and form reset.

## Run
Open `index.html` in a modern browser. No build step or JavaScript libraries are required.

## Files
Each task has a separate JavaScript file in `js/`. Styling is in `css/styles.css`.

## Before submission
Create/push to your own GitHub repository and paste the repository URL into the report.
